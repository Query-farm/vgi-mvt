# Shared example standard

These examples follow the [v0.3.31 shared standard](https://github.com/Query-farm/vgi-example-notebooks/blob/v0.3.31/docs/standard.md) and its [coverage evidence format](https://github.com/Query-farm/vgi-example-notebooks/blob/v0.3.31/docs/coverage.md).

The notebook environment and lock pin the shared package. Presentation and fixture companions are hash-verified from an immutable public revision. SVG is the default figure format. Worker source and root dependencies are unchanged; existing green source CI is reused for this notebook-only publication.
